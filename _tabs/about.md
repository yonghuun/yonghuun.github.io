# 고용훈

> 문제의 원인을 분석하고, 수치로 개선하는 백엔드 개발자입니다.

Java와 Spring Boot를 중심으로 백엔드 시스템을 개발하고 있습니다.

기능을 구현하는 데서 끝내지 않고 로그, SQL 실행 계획, 응답 시간을 확인하며 병목의 원인을 찾는 과정을 좋아합니다.

## 주요 관심 분야

- 백엔드 API 설계
- MySQL 쿼리 및 인덱스 최적화
- Redis를 활용한 데이터 처리
- WebSocket 기반 실시간 상태 동기화
- 동시성 제어와 장애 대응

## 대표 경험

### TripCrew

여행지 검색과 일정 관리를 제공하는 여행 플랫폼입니다.

- 관광지 목록 조회: **506ms → 52ms**
- 키워드 검색: **523ms → 4ms**
- 불필요한 JOIN 제거
- count 쿼리 분리
- MySQL FULLTEXT 인덱스 적용

### WebRTC 요트다이스

휴대폰 모션과 실시간 통신을 활용한 멀티플레이 게임입니다.

- 서버 기준 라운드 상태 관리
- deadline 기반 타이머 동기화
- 중복 제출 방지
- 재접속 시 게임 상태 복구

### 말랑오더

AI 음성 주문을 지원하는 키오스크 서비스입니다.
