# 고용훈

> 문제의 원인을 분석하고, 수치로 개선하는 백엔드 개발자입니다.

저는 Java와 Spring Boot를 중심으로 백엔드 시스템을 개발합니다.

기능 구현으로 끝내지 않고 로그, SQL 실행 계획, 응답 시간을 확인하며 병목의 원인을 찾는 과정을 좋아합니다.

TripCrew 프로젝트에서는 불필요한 JOIN과 Full Table Scan을 분석하고, count 쿼리 분리와 FULLTEXT 인덱스를 통해 검색 응답 시간을 개선했습니다.

현재는 WebSocket과 WebRTC 기반 게임 프로젝트에서 상태 동기화, 라운드 관리, 재접속, 동시성 제어를 경험하고 있습니다. 게임 상태와 시그널링에는 WebSocket을 함께 사용합니다.

## 관심 분야
